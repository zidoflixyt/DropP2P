Why DropP2P

Built like a pipe, not a warehouse

Most file services upload your data to a server, hold it, and hope you pay before it expires. DropP2P skips the warehouse entirely — your file flows straight from one device to the other.

Zero Cloud Storage

Files are streamed directly between devices over WebRTC data channels. No copy of your data is ever written to any server, so there is nothing to breach, expire, or mine for training data.

End-to-End Encryption

Every WebRTC data channel is mandatorily encrypted with DTLS. The encryption is enforced by the browser itself — neither DropP2P nor anyone in between can read the stream.

Unlimited File Size

10 GB of RAW photos, 50 GB of 4K B-roll — the size ceiling is your own disk, not a subscription tier. There is no upload cap because there is no upload destination.

Chunk Streaming Engine

Files are sliced into 64 KB chunks and streamed sequentially with bufferedAmount backpressure, so a 50 GB transfer runs smoothly even on a low-RAM phone without ever loading the file into memory.

Cross-Device Compatibility

Phone to PC, PC to tablet, Android to iPhone — if it runs a modern browser, it can send or receive. No app install, no account, no cable.

How it works

From your device to theirs, in five stages

  1. 1

    Select File

    Drag and drop any file onto the send panel. It stays on your device — nothing is uploaded.

  2. 2

    Share 6-Digit Code

    DropP2P generates a room code, QR code, and one-click link. Send it to your friend however you like.

  3. 3

    Real-time P2P Handshake

    STUN punches through NAT; a TURN relay steps in only when firewalls are strict. A direct encrypted channel opens.

  4. 4

    High-Speed Stream

    The file streams as 64 KB chunks with backpressure control. Live speed and ETA are shown on both devices.

  5. 5

    Secure Download

    After a brief finalization screen, the file is reassembled locally and saved — the channel then closes for good.

One honest limitation you should know

Because DropP2P streams files directly between devices with no intermediate server storage, both the sender and the receiver must remain online with this page open at the same time, for the entire duration of the transfer. If either side disconnects mid-transfer, the transfer must be restarted. This is the trade-off for unlimited size, zero storage, and full privacy — and for most direct handoffs, it is exactly what you want.

FAQ

Frequently asked questions

Does DropP2P store my files on a server?
No. DropP2P has no cloud storage at all. Your file is streamed directly from your device to the other person's device over an encrypted WebRTC connection, so no copy ever exists on our infrastructure.
Can I send files between different cities or networks?
Yes. DropP2P uses Google's public STUN servers plus free TURN relay fallback, so connections succeed across different Wi-Fi networks, 4G and 5G, even behind strict NATs and firewalls.
Is there a file size limit?
No. Files are sliced into 64 KB chunks and streamed sequentially with memory-safe backpressure, so transfers of 10 GB, 50 GB or more work as long as both devices have enough free disk space for the final download.
Do both people need to be online at the same time?
Yes. Because files are streamed directly between devices with no intermediate server storage, the sender and receiver must both keep the page open for the duration of the transfer.
Does DropP2P work on phones?
Yes. It works in modern mobile browsers. When a transfer starts, the Screen Wake Lock API keeps the screen awake, but you should still keep the tab in the foreground for the best speeds.
What happens if I lock my phone screen mid-transfer?
The Wake Lock keeps the screen on while the tab is visible, but some aggressive phone manufacturers may still pause network activity in the background. Keep the screen unlocked and the tab open until the transfer finishes.
Is the transfer encrypted?
Yes. All WebRTC data channels are encrypted with DTLS (Datagram Transport Layer Security) by default, so the data is encrypted in transit between the two devices.
Do I need to create an account?
No registration, no email, no sign-up. Generate a 6-digit code, share it, and start transferring immediately.
Which browsers are supported?
Any modern browser with WebRTC support: Chrome, Edge, Firefox, Safari, Opera, and their mobile versions.
How is DropP2P free?
WebRTC infrastructure is free to use and files never touch a server, so running costs are near zero. The service is supported by non-intrusive ads, including a single short ad before your final download.
